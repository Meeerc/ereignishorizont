# Ereignishorizont

Ein Schwarzes Loch, in Echtzeit im Browser geraytract (WebGL-Shader, Schwarzschild-Metrik), dazu drei Canvas-Simulationen: N-Körper-Gravitation, 60 chaotische Doppelpendel und der Lorenz-Attraktor.

Live: https://meeerc.github.io/ereignishorizont/

Eine einzige `index.html`, keine Abhängigkeiten ausser Google Fonts.
